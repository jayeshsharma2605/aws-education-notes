# AWS Education Notes

*Author: Jayesh Sharma*

A beginner-friendly AWS learning repository with original explanations, practical examples, architecture diagrams, safety notes, and interview questions.

## Study Guides

1. [AWS Account Setup & Cloud Computing Models (IaaS, PaaS, CaaS, FaaS, SaaS)](AWS_Account_Setup_and_Cloud_Service_Models.md) — Create and secure an AWS account, understand cloud service models, and map them to AWS services.
2. [AWS Global Infrastructure (Part 1): Regions, Availability Zones, Local Zones & Edge](AWS_Global_Infrastructure_Part_1_Regions_AZs_Local_Zones_Edge.md) — Region selection, multi-AZ resilience, regional and zonal resources, Local Zones, CloudFront edge caching and interview practice.

## How to use these notes

1. Open the guide and read the simple examples first.
2. Use the Mermaid diagrams to connect the concepts visually (GitHub renders Mermaid blocks).
3. Answer the interview questions without looking at the notes.
4. For hands-on exercises, follow current AWS pricing and Free Tier guidance; delete unused resources after every lab.
